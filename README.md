# The-Engineering-Almanac
Curated resources on building production-grade AI systems, databases, and scalable software.

## Why this repo?

There is no shortage of tutorials on the web.

There is a shortage of high-quality thinking on:
- Making AI reliable in production
- Scaling systems without losing sanity
- Designing databases and distributed systems properly
- Engineering for second-order effects

This repository is my curated collection of production-grade engineering wisdom which is updated frequently based on what all I come across online (in no particular order).
